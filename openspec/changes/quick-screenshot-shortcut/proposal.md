## 为什么需要这个变更

目前，触发截图采集只能通过打开监控面板，系统根据屏幕变化自动采集。用户需要一个更快的方式手动触发单次截图采集和事件处理，而无需打开监控窗口，提升工作流效率。

## 变更内容

1. **全局快捷键**：注册一个可配置的全局快捷键（默认：`Cmd+Shift+S`），触发即时截图采集和事件处理，无需打开监控面板。

2. **快捷键设置界面**：在设置页面（"触发规则"标签页）添加快捷键配置界面，用户可自定义快捷键组合。

3. **按需采集**：当快捷键被触发时：
   - 立即采集当前屏幕
   - 通过现有的 EventWorkflow（或旧流程）处理
   - 生成知识条目并触发事件
   - 不打开监控窗口，采集在后台静默执行

4. **设置持久化**：将自定义快捷键配置存储在现有设置系统中（数据库）。

## 能力

### 新增能力
- `quick-capture-shortcut`：用于按需截图采集的全局键盘快捷键，无需打开监控 UI
- `shortcut-settings-ui`：用于配置快捷键的设置界面

### 修改的能力
- （无 - 采集逻辑复用现有 MonitoringService 功能）

## 影响范围
- **前端**：Settings.tsx - 添加快捷键配置 UI
- **主进程**：index.ts - 添加 globalShortcut 注册，MonitoringService.ts - 添加手动触发方法
- **数据库**：可能需要扩展 `app_settings` 存储快捷键配置
- **依赖**：electron globalShortcut 模块（已是 Electron 的一部分）
